# `/platform` — Venuewise platform plane

Venuewise-level surfaces that operate **across** workspaces: platform administration and cross-workspace reporting (including the platform-vs-workspace revenue separation from VPS §10).

**Status: empty scaffold (Milestone 2).** No functionality yet. This directory exists so later milestones have a home for the platform plane without restructuring. Distinct from `/venuewise-admin/` and `/admin/`, which are existing product-specific admin pages and are **not** moved or changed.

Populated in later waves once tenancy (Wave 1) exists, since "cross-workspace" has no meaning until workspaces do.
