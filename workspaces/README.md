# `/workspaces` — per-workspace branded entry points

Config-driven entry points for each Business Workspace (VPS §4). Each subfolder is a thin, branded shell that loads shared engine modules and a workspace's branding/settings — **not** a bespoke app (VPS Principle 3 — Configuration over Custom Code).

**Status: empty scaffold (Milestone 2).** No workspaces yet. The first occupant (much later, and only after tenancy lands) will be `ddh/` — DDH Operating Company and its two divisions — configured as workspace data, per VPS §9.

Nothing here is built during Wave 0. Do **not** begin DDH Athlete Development or DDH Home Services here; Wave 0 builds only the foundation those will eventually consume.
